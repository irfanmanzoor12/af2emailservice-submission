# Skills I chose

I searched skills.sh on 2 November 2026 for "email marketing", "email sequence", "campaign plan" and "resend". Nothing is installed yet.

## Use these

**1. Anthropic's marketing plugin, for planning and writing campaigns**
- Where: `anthropics/knowledge-work-plugins` (the `marketing` plugin). It has 34,379 GitHub stars.
- It came up as `campaign-plan` (3.3K installs) and `email-sequence` (3K installs). The plugin also includes `brand-review`.
- Why: Anthropic, the company that makes Claude, publishes it. It covers the whole job in one place: plan the campaign, write the emails, then check them against the brand.

**2. Resend's own skills, for sending email**
- Where: `resend/resend-skills` (the `resend` skill, 24K installs) and `resend/email-best-practices` (8.2K installs).
- Why: the `resend` organization on GitHub is the real company (it links to resend.com), so these skills match how Resend actually works. They have fewer stars (208 and 146) than the big marketing repos. That's normal for a company's own tool repo, and it doesn't count against them.

## Avoid these

**1. `mbfinotti/sales-skills` (cold-email and outbound-sequence skills)**
- Each skill shows about 31K installs, but the GitHub repository has only **3 stars**.
- That many installs with almost no stars is a warning sign that the numbers may be inflated. It's also about cold outreach to strangers, not emailing people who signed up to a waitlist.

**2. `caffeinelabs/skills@extension-email-marketing`**
- It shows 29.3K installs, but its repository has only **2 stars**. I don't know the publisher, and it isn't an official email or marketing company.

(Also skip `code.deepline.com@deepline-ads-audiences`, with 26.9K installs: there's no public GitHub repository I could check.)

## How I decided

Three things to check before installing any skill:

1. **Who publishes it.** Prefer the company behind the tool (Anthropic, Resend) or a well-known author. Make sure the GitHub account really belongs to them.
2. **Whether the stars match the installs.** Install counts can be faked, and stars are harder to fake. Thousands of installs with only a handful of stars is a red flag.
3. **Whether it fits the job and is kept up to date.** Read what the skill actually does (a waitlist launch is not cold outreach), check when it was last updated, and look at the files before installing. A skill can run commands on your computer.
