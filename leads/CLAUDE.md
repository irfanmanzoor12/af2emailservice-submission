# Leads folder rules

These rules apply only to files in this folder.

- Everyone in `leads.csv` is a made-up practice person. None of them are real.
- Never add real people or real email addresses.
- Every row needs a value in the `consent` column. Don't add a row without one.
- Never change the `@example.com` addresses. That domain is reserved and can't receive mail, so no real person is ever emailed.
